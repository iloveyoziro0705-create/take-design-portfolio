ミライ寮

MIRAI-RYO — Live-in Job Matching

Type
自主制作
Category
Landing Page / AI / System
Field
Job · Housing · 住み込み求人
Year
2026

01Overview概要

住み込み求人マッチングLP。30秒診断クイズで4タイプに分岐し、タイプに合わせた求人・寮情報を提案します。ライフシミュレーターも実装しました。

自主制作のコンセプト作品です。ブランド名・人物・料金・実績数値などは作品内の設定であり、実在の企業・店舗・成果を示すものではありません。

02Background想定した背景・課題

住み込み求人は「仕事」と「住まい」を同時に決める必要があり、応募前の不安が大きい領域です。一律の求人一覧ではなく、自分に合う選択肢から見せることを課題に設定しました。

03Purpose & Policy目的と制作方針

目的：住み込み求人への応募獲得

ファーストビュー直後に短い診断を置き、回答に応じて4タイプへ分岐させました。タイプ別にページ構成を切り替え、新生活のイメージをシミュレーターで具体化しています。

04Design Pointsデザイン・構成上の工夫

  1. 30秒で終わる診断クイズで、最初の行動のハードルを下げる
  2. 診断結果に応じて、求人・寮情報の見せ方をタイプ別に切り替え
  3. ライフシミュレーターで、住み込み後の生活を数字とイメージで具体化

05Implementation実装内容・技術

  • HTML
  • CSS
  • JavaScript
  • Quiz Logic
  • Simulator
