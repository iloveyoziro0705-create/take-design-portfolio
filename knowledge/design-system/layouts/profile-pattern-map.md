| PROFILE-003 | HERO型（人物メイン）| 代表者の顔が最初から一貫 |
| PROFILE-013 | HERO型（フルワイド背景）| 世界観統一 |

| PROFILE-061 | 任意Hero | CTA直前に置くため相性問わず |
| PROFILE-062 | 医療系Hero | 院長＋清潔感の統一 |

### PROFILE → 相性の良いFeatureパターン

| PROFILE-ID | 相性の良いFeature | 理由 |
|-----------|----------------|------|
| PROFILE-001 | FEATURE-041（選ばれる理由）| 代表＋強みの流れ |
| PROFILE-003 | FEATURE-043（悩み→解決）| 理念→解決策の流れ |
| PROFILE-047 | FEATURE-017（大数字）| 士業の実績→専門性の流れ |
| PROFILE-053 | FEATURE-001〜065（任意）| 統合型につきFeatureと一体化 |

### PROFILE → 相性の良いVoiceパターン

| PROFILE-ID | 相性の良いVoice | 理由 |
|-----------|--------------|------|
| PROFILE-001 | VOICE-013（写真左インタビュー）| 代表→顧客の流れで信頼積層 |
| PROFILE-002 | VOICE-039（B/A体験談）| 院長紹介→施術後の変化 |
| PROFILE-052 | VOICE-001〜055（任意）| 統合型につき直接融合 |
| PROFILE-061 | VOICE-028（総合評価）| フル版の前後に評価バッジ |

### PROFILE → 相性の良いFlowパターン

| PROFILE-ID | 相性の良いFlow | 理由 |
|-----------|-------------|------|
| PROFILE-001 | FLOW-001（縦3ステップ）| 相談の流れを見せる |
