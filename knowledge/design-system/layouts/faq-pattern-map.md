## MAP 03 ｜ LPフローにおけるFAQ配置マップ

### 配置位置別の最適FAQ

```
ページ最上部（Hero直後）
└── 使わない（Heroとの相性が悪い）

ページ中盤（Feature/Voice/Flow後）
├── FAQ-036（最重要3件：コンパクト）
├── FAQ-052（インラインFAQ：各セクション末尾）
└── FAQ-011（カテゴリー区切り：多質問整理）

ページ下部（CTA直前）← 最も重要な配置
├── FAQ-026（FAQ＋CTA統合：最強）
├── FAQ-001（シンプルアコーディオン：定番）
├── FAQ-017（末尾LINE誘導：日本LP定番）
├── FAQ-020（美容サロン特化）
├── FAQ-021（士業特化）
├── FAQ-024（映像制作特化）
└── FAQ-036（最重要3件のみ）

ページ全体（常時表示）
└── FAQ-049（フローティングポップアップ）
```

### LP長さ別の推奨FAQ数

| LP種類 | 推奨配置 | 質問数 |
|--------|---------|--------|
| ショートLP（5セクション以内）| FAQ-036 のみ | 3件 |
| ミドルLP（6〜10セクション）| FAQ-001 or FAQ-020 | 5〜7件 |
| ロングLP（11セクション以上）| FAQ-011 or FAQ-012 | 8〜15件 |
| ランディングページ（最短CV重視）| FAQ-026 | 4〜6件 |

## MAP 09 ｜ TAKE movie 映像制作LP向け推奨フロー

```
[LP構造例]
Hero
  ↓
Feature（サービス特徴）
  ↓
Flow（FLOW-039：ダーク映像制作プロセス）
  ↓
Voice（お客様の声）
  ↓
FAQ-024（映像制作特化FAQ）← ここ
  ├── Q: 費用はどのくらいかかりますか？
  ├── Q: どのくらいの期間がかかりますか？
  ├── Q: 修正は何回まで対応できますか？
  ├── Q: どんな動画でも制作できますか？
  ├── Q: 著作権はどこに帰属しますか？
  ├── Q: 撮影場所の指定はできますか？
  └── Q: 見積もりだけでも相談できますか？
  ↓
FAQ-017（末尾LINE誘導）← 「解決しない場合はLINEへ」
  ↓
CTA-046（LINE見積もり相談）← 最終CTA
```

### 想定Q&A（TAKE movie向けサンプル）

| Q | A のポイント |
|---|-----------|
| 費用はどのくらいかかりますか？ | 制作内容・尺・スタイルにより変動。まずは無料見積もりへ |
| どのくらいの期間がかかりますか？ | 撮影〜納品まで目安X〜Y週間。急ぎの場合はご相談 |
| 修正は何回まで対応できますか？ | 基本◯回まで無料。それ以降は別途ご相談 |
| どんな動画でも制作できますか？ | 企業PR・採用・商品紹介・式典・SNS動画等に対応 |
| 著作権はどこに帰属しますか？ | 納品後はお客様に帰属。詳細は契約時にご確認 |
| 撮影場所の指定はできますか？ | 関東エリア中心。遠方の場合は交通費実費 |
| 見積もりだけでも相談できますか？ | はい、無料でご相談いただけます |

## MAP 10 ｜ FAQ → CV パスフロー

```
【最短CVパス（3ステップ）】
1. FAQ-036（最重要3件）→ 2. 解消 → 3. CTA-001

【標準CVパス（4ステップ）】
1. FAQ-001（基本5〜8件）→ 2. 解消 → 3. FAQ-017末尾LINE → 4. LINE登録

【完全CVパス（5ステップ）】
1. FAQ-024（業種特化）→ 2. 不安解消 → 3. FAQ-019（回答内CTA）
→ 4. FAQ-017（末尾LINE誘導）→ 5. CTA-046（LINE見積もり）

【LINEファネル（美容サロン）】
FAQ-020 → FAQ-017 → LINE登録 → 予約

【フォームファネル（BtoB）】
FAQ-021 → FAQ-018 → フォーム送信 → 相談アポ
```

## MAP 11 ｜ FAQ要素チェックリスト

LP制作時に確認すべき項目：

```
基本確認
□ FAQ-IDを指定して使用している（ゼロ設計していない）
□ 業種に合ったFAQを選んでいる（業種別MAP参照）
□ FAQ末尾にCTA誘導がある（FAQ-017 or FAQ-026推奨）
□ スマホでタップ領域が44px以上確保されている

質問内容の確認
□ 料金・費用への回答がある
□ キャンセル・解約への回答がある
□ 初心者でも大丈夫という安心の回答がある
□ 問い合わせ方法への案内がある

上級者確認
□ 最も重要な質問には回答内CTA（FAQ-019）を検討したか
□ FAQにない疑問はLINE/フォームで受け取れるか（FAQ-017/018）
□ 質問数が多い場合はカテゴリー分割（FAQ-011/012）を使っているか
□ CTA直前には最重要FAQ3件のみ（FAQ-036）を検討したか
```
