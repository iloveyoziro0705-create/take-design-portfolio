## MAP 08 ｜ 素材あり・なし別 選択ツリー

```
顔写真あり？
├─ YES → 長文（5行以上）あり？
│         ├─ YES → VOICE-013（インタビュー詳細）
│         │         VOICE-041（交互インタビュー）
│         └─ NO  → VOICE-001（3カード定番）
│                   VOICE-038（年代＋吹き出し）
│                   VOICE-016（吹き出し）
└─ NO  → 動画あり？
          ├─ YES → VOICE-023（大動画フォーカス）
          │         VOICE-043（動画＋テキスト）
          └─ NO  → Google口コミあり？
                    ├─ YES → VOICE-019（Google口コミ風）
                    └─ NO  → VOICE-028（総合評価大表示）
                              VOICE-035（大引用文字のみ）

Before/After写真あり？
├─ YES → 美容系 → VOICE-039（美容LP定番）
│         美容系以外 → VOICE-025（汎用B/A）
└─ NO  → スキップ
```

   → 素材・感情・業種から逆引きでIDを特定

制作フロー：
❌ 「お客様の声を作ろう」→ ゼロからHTMLを書く
✅ 「VOICE-039を使う」→ ライブラリから選択 → 素材を当てはめ

素材確認チェックリスト（ID選択前に確認）：
□ 顔写真あり/なし
□ Before/After写真あり/なし
□ 動画証言あり/なし
□ Googleレビューあり/なし
□ 年代・性別の属性情報あり/なし
□ 長文証言（5行以上）あり/なし
□ 会社名・ロゴあり/なし（BtoB）
□ 星評価・件数あり/なし

## Production Rules 追記内容

```
## Voice セクション設計フロー（Feature次に必ず実行）

Step 1: 利用できる素材を確認（顔写真/動画/B-A/プラットフォーム評価など）
Step 2: voice-ranking.md で業種・CV目的に合うIDを特定
Step 3: voice-layout-library.md でそのIDの仕様を確認
Step 4: voice-pattern-map.md で組み合わせパターンを選択
Step 5: VOICE-ID を指定してコーディング開始

禁止事項：
- ライブラリを参照せずVoice Sectionをゼロ設計すること
- 素材なしに顔写真を要求するパターン選択（顔写真なしでも可能なIDがある）
- 重複パターンを新規追加すること（統合推奨）
```
