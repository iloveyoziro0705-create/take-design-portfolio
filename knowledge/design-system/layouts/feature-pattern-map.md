# Feature Pattern Map

**バージョン**: 1.0
**作成日**: 2026-06-28
**用途**: 業種 × CV目的 × ターゲット からFeatureパターンを素早く選定する

---

## 使い方

1. **業種** からパターン候補を絞る
2. **CV目的** で候補を絞り込む
3. `feature-ranking.md` でスコア確認
4. `feature-layout-library.md` で詳細確認
5. 採用パターンを記録して制作開始

## 移植対象外とした独立側セクション（監査結果メモ）

以下は独立knowledge側`feature-pattern-map.md`に存在するが、今回の監査で移植不要と判断した：

- **MAP 05｜スコア×汎用性マトリクス**：各パターンの評価スコアはすでに各パターン本文の「評価」テーブルに保持済みであり、2軸プロットは既存データの可視化に過ぎないため、情報として重複（D判定）。
- **MAP 07｜FEATURE-ID クイックリファレンス**：カテゴリ分類は「レイアウト構造別インデックス」「副次分類 / クロス分類インデックス」（本ファイル既存セクション）にすでに包含されており、Legacy救出パターン表と合わせて重複（B判定）。
- **AGENTS.md追記内容／Production Rules追記内容**：パターンデータではなく制作プロセス上のルール文書。pattern-map.mdの範囲外であり、移植するならgovernance.mdやCLAUDE.md相当のドキュメントが適切（3:有用だが本ファイルの対象外）。
