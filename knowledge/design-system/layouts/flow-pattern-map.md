## MAP 02 ｜ 不安別 逆引きマップ

### 「難しそう / 手続きが面倒」を解消

> シンプルさと手軽さを前面に押し出す

最強: **FLOW-046**（「たった3ステップ」）→ **FLOW-001** → **FLOW-006**

| ID | 解消アプローチ |
|----|--------------|
| FLOW-046 | セクション見出しに「たった3ステップ」を明記 |
| FLOW-001 | 縦3ステップで最小構成 |
| FLOW-006 | 横3ステップ＋矢印で一目で分かる |
| FLOW-021 | アイコンで「読まなくても分かる」 |
| FLOW-008 | 番号大強調で「3つだけ」を印象付け |
| FLOW-032 | ✓完了型で「すぐ終わる感」を演出 |

---

### 「時間がかかりそう」を解消

> 所要時間の明示で「思ったより短い」を伝える

最強: **FLOW-005**（所要時間バッジ）→ **FLOW-028** → **FLOW-014**（期間付き）

| ID | 解消アプローチ |
|----|--------------|
| FLOW-005 | 各ステップに「約○分」バッジ |
| FLOW-028 | 番号と時間バッジのダブル表示 |
| FLOW-014 | 縦タイムラインに期間バッジ（「約1週間」） |
| FLOW-033 | ウィザード型で「残り○ステップ」の見通し |

---

### 「料金が分からない」を解消

> 費用の透明性で「いきなりお金はかからない」を伝える

最強: **FLOW-041**（費用タイミング明示）→ **FLOW-045**（料金＋CTA）

| ID | 解消アプローチ |
|----|--------------|
| FLOW-041 | 費用発生ステップに「無料」「要見積もり」バッジ |
| FLOW-045 | 各ステップに概算料金を明示 |
| FLOW-035 | 「ご相談まで無料」を最初のステップに明記 |

---

### 「初めてで不安」を解消

> 「何が起きるか」の事前予告で安心を作る

最強: **FLOW-034**（美容施術写真付き）→ **FLOW-042**（安心材料統合）→ **FLOW-020**（担当者顔）

| ID | 解消アプローチ |
|----|--------------|
| FLOW-034 | 施術の各シーン写真で視覚的に予告 |
| FLOW-042 | 各ステップに安心バッジ（「勧誘なし」等） |
| FLOW-020 | 担当者・スタッフ顔写真付き |
| FLOW-004 | 縦ステップ各シーン写真 |
| FLOW-029 | お客様視点ストーリー「あなたは〇〇します」 |

---

### 「担当者が誰か分からない」を解消

最強: **FLOW-020**（担当者顔写真付き）→ **FLOW-034**（施術スタッフ写真）

---

### 「途中でやめられるか」を解消

最強: **FLOW-042**（各ステップに安心バッジ「いつでもキャンセル可」）→ **FLOW-035**（「ご契約は任意」明記）

```css
/* 縦ステップ基本スタイル */
.flow-step {
  display: flex;
  align-items: flex-start;
  gap: 16px;
  padding: 24px 0;
  border-bottom: 1px solid #eee;
}

.flow-number {
  width: 48px;
  height: 48px;
  border-radius: 50%;
  background: var(--accent-color);
  color: #fff;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 20px;
  font-weight: bold;
  flex-shrink: 0;
}

/* ステップ間の縦線 */
.flow-line {
  width: 2px;
  height: 40px;
  background: var(--accent-color);
  margin: 0 23px; /* 丸の中央に合わせる */
  opacity: 0.3;
}
```

### 横ステップ型（スマホでは縦変換）
```css
.flow-horizontal {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

/* スマホで縦1列 */
@media (max-width: 768px) {
  .flow-horizontal {
    grid-template-columns: 1fr;
  }
  
  .flow-arrow {
    transform: rotate(90deg); /* → を ↓ に変換 */
    margin: 8px auto;
  }
}
```
