## SECTION 02 ｜ 推奨写真構図ガイド

### 写真タイプ別解説

#### TYPE-01 ｜ 正面バスト（定番・最も汎用）
- **距離**: 胸〜首元まで
- **視線**: カメラ正面
- **背景**: 白・グレー・オフィス・自然
- **向いている**: 士業・コンサル・医療・コーポレート
- **効果**: 誠実さ・信頼感・プロフェッショナル感

#### TYPE-02 ｜ 斜め向きバスト（柔らかい印象）
- **距離**: 胸〜首元まで
- **視線**: 少し斜め〜カメラ
- **背景**: ぼかし（ポートレートモード）
- **向いている**: 美容・スクール・コーチング
- **効果**: 親しみやすさ・話しかけやすさ

#### TYPE-03 ｜ 笑顔フルフェイス（親近感最優先）
- **距離**: 顔メイン
- **視線**: カメラ正面
- **背景**: ぼかし
- **向いている**: 採用・美容・飲食
- **効果**: 安心感・親近感・好感度

#### TYPE-04 ｜ 仕事中・作業中（本物感）
- **距離**: 全身または上半身
- **視線**: 作業に向いている（カメラ見ていない）
- **背景**: 実際の仕事場
- **向いている**: 飲食・美容・クリエイター・職人
- **効果**: 本物感・誠実さ・技術への信頼

#### TYPE-05 ｜ 全身立ち（体型・スタイル訴求）
- **距離**: 全身
- **視線**: カメラ正面または斜め
- **背景**: スタジオ白抜きまたは自然環境
- **向いている**: フィットネス・パーソナルトレーナー
- **効果**: 結果を体現している説得力

#### TYPE-06 ｜ 白衣・制服着用（専門性）
- **距離**: バスト〜上半身
- **視線**: カメラ正面
- **背景**: クリニック・サロン内
- **向いている**: 医療・歯科・美容師
- **効果**: 専門家のお墨付き感

#### TYPE-07 ｜ カジュアル・自然体（採用・SaaS）
- **距離**: バスト
- **視線**: カメラまたは遠くを見る
- **背景**: オフィス・カフェ・自然
- **向いている**: スタートアップ・採用・カジュアルブランド
- **効果**: フレンドリー・話しかけやすさ

### NG写真パターン
| NGパターン | 代替案 |
|-----------|--------|
| 暗すぎる・顔が見えない | 自然光またはレフ板を使用 |
| スマホ自撮り（自撮り感あり）| プロまたは友人撮影 |
| 背景が散らかっている | 白背景またはぼかし |
| 集合写真から切り抜き | 個人専用写真を用意 |
| 顔が小さすぎる | バストショット以上にトリミング |
| 古い写真（10年以上前）| 現在の外見に更新 |

#### 美容・エステ系

#### 士業系

#### コンサル・コーチ系
- 経営コンサルタント
- 認定ライフコーチ
- ビジネスコーチ
- 〇〇専門コンサルタント

#### スクール・教育系
- 〇〇スクール 代表講師
- 〇〇受講生〇〇名を指導
- 〇〇協会認定インストラクター
- 元〇〇（前職）現役講師

#### フィットネス系
- NSCA認定パーソナルトレーナー
- ヨガRYT200取得インストラクター
- ピラティスインストラクター
- 〇〇ジム トレーナー

#### SaaS・テック系
- 代表取締役CEO / CTO
- 元〇〇エンジニア
- プロダクトマネージャー
- フルスタックエンジニア

### 肩書き表示ルール
1. **資格は正式名称**で表示（略称より信頼性UP）
2. **登録番号があれば記載**（士業は特に効果大）
3. **複数ある場合は3つ以内**に絞る（多すぎると信頼性が下がることも）
4. **現職を最上部に**（古い経歴より今が大事）
5. **業界特有の資格は説明文を添える**（一般人がわからない資格は補足必須）

## SECTION 04 ｜ 資格表示方法ガイド

### 表示形式A ｜ テキストリスト型
```
▼ 保有資格・認定
・〇〇専門医（日本〇〇学会認定）
・医学博士（〇〇大学）
・〇〇認定医 第〇〇〇号
```
**向いている**: テキスト主体のシンプルなプロフィール

### 表示形式B ｜ バッジ型（推奨）
```
[アイコン] 〇〇専門医   [アイコン] 医学博士
[アイコン] 〇〇認定    [アイコン] △△取得
```
**向いている**: 視覚的インパクトが必要なLP。カードまたは枠囲みで強調

### 表示形式C ｜ チェックリスト型
```
✅ 税理士（登録第〇〇〇〇号）
✅ 公認会計士
✅ 中小企業診断士
```
**向いている**: 士業・コンサル。一覧性が高く「ある・ない」が明確

### 表示形式D ｜ 認定証スキャン型
```
[認定証の写真]  [資格証の写真]
〇〇専門医認定証   〇〇資格証
```
**向いている**: 医療・整体・特殊資格。実物を見せることで「本物感」演出

### 資格表示の優先順位
1. **国家資格・公的資格**（最優先）
2. **業界団体認定資格**（次優先）
3. **民間認定資格**（補足として）
4. **研修・セミナー修了証**（任意）

## SECTION 05 ｜ 実績表示方法ガイド

### 実績数字の見せ方

#### パターンA ｜ 大数字型（最もインパクト大）
```
相談件数    指導年数    満足度
1,200件以上  15年       98%
```
- 数字は大きく（72〜96px推奨）
- 単位・説明文は小さく添える
- 3〜4項目が見やすい上限

#### パターンB ｜ 箇条書き実績型
```
・相談件数 累計1,200件以上
・業界経験 15年
・顧客満足度 98.2%（2024年調査）
・著書 3冊
```

#### パターンC ｜ 実績タグ型
```
[1,200件以上の相談実績] [業界歴15年] [著書3冊]
```
pill型のタグで視覚的に見せる

### 数字が取れない場合の代替表現
| 実態 | 代替表現 |
|------|---------|
| 件数が少ない | 「〇年の経験」「丁寧な対応を心がけています」 |
| 数字が不明 | 「多くのお客様に」→「述べ〇〇名様に」（概算可）|
| まだ実績なし | 経歴・資格・理念で代替 |

### 実績表示のルール
1. **具体的数字**が最も信頼性が高い
2. **測定期間・出典**を添えると信頼性UP（「2024年調査」など）
3. **盛りすぎない**（「10,000件以上」など不自然な数字は逆効果）
4. **更新する**（古い数字は信頼性DOWN）

## SECTION 06 ｜ ブランドストーリー構成ガイド

### 基本構成テンプレート「5段階ストーリー」

```
① BEFORE（過去の自分・問題）
   「私も以前は〇〇に悩んでいました」
   ↓
② TRIGGER（転機・出会い）
   「そんな時、〇〇と出会い」
   ↓
③ JOURNEY（変化・学び）
   「〇〇を学び、実践し続けた結果」
   ↓
④ RESULT（現在の成果）
   「今では〇〇人の方の〇〇を解決できています」
   ↓
⑤ MESSAGE（読者へ）
   「同じ悩みを持つあなたに、〇〇できるお手伝いをしたい」
```

### 業種別ストーリー例

#### 美容師・エステティシャン
```
BEFORE: 自分自身がコンプレックスを持っていた
TRIGGER: 〇〇サロンとの出会い・自分の変化を体験
JOURNEY: 技術習得・修行・独立
RESULT: お客様〇〇名の変化を担当
MESSAGE: 同じコンプレックスを持つ方に寄り添いたい
```

#### 士業（税理士・弁護士）
```
BEFORE: 〇〇で困っている事業者を見てきた
TRIGGER: その問題を解決したくて資格取得
JOURNEY: 〇〇年の実務経験・専門分野の研鑽
RESULT: 〇〇件の問題解決を実現
MESSAGE: 一人で悩まず、まず相談してほしい
```

#### スクール・講師
```
BEFORE: 自分が〇〇を習いたかったができなかった
TRIGGER: 独学で習得・可能性を実感
JOURNEY: 試行錯誤・独自メソッド開発
RESULT: 〇〇名が達成
MESSAGE: 諦めなかった人が変わる姿を見たい
```

### ストーリー文字数の目安
| コンテキスト | 文字数 |
|------------|--------|
| キャッチコピー | 20〜40文字 |
| 短文メッセージ | 100〜200文字 |
| プロフィール本文 | 300〜500文字 |
| ストーリー全文 | 800〜1500文字 |

## SECTION 08 ｜ 信頼性を高める情報設計ルール

### 信頼シグナル優先順位
```
1位: 顔写真（最重要。写真がないと信頼性が大幅低下）
2位: 国家・公的資格（客観的証明）
3位: 実績数字（具体的な成果）
4位: メディア掲載・受賞（第三者評価）
5位: 経歴・学歴（バックグラウンドの証明）
6位: お客様の声（社会的証明）
7位: ストーリー・理念（共感）
```

### 情報量の最適解
| セクション規模 | 推奨情報量 |
|-------------|---------|
| ミニプロフィール（他セクションに付属）| 写真＋名前＋肩書き＋一言のみ |
| スタンダードプロフィール | 写真＋経歴＋資格＋メッセージ |
| フルプロフィール（CTA直前）| 全情報＋実績数字＋メディア掲載 |

### CTAとの距離設計
| 配置 | 推奨CTAタイプ |
|------|------------|
| プロフィール内にCTA統合 | PROFILE-051（CTA統合型）|
| プロフィール直後にCTA | CTA-039 / CTA-009 |
| ページ最下部にプロフィール→CTA | PROFILE-009（中央配置CTA直前）|

## SECTION 09 ｜ アンチパターン（避けるべき情報設計）

| アンチパターン | なぜNG | 改善策 |
|-------------|-------|--------|
| 写真なし | 信頼性が最大50%低下 | 最低限の写真を用意 |
| 自己PRだけで実績なし | 「言うだけ」感 | 数字・資格・メディアで証明 |
| 文字が多すぎる | 読まれない | 300文字以内にまとめ詳細は別ページへ |
| 資格を並べすぎる（10個以上）| 信頼より混乱 | 上位3〜5個に絞る |
| 古すぎる写真 | 今の人と違う感 | 定期的に更新 |
| 謙遜しすぎる文章 | 弱く見える | 実績は自信を持って記載 |
| CTAが遠すぎる | 信頼した後に行動できない | プロフィールの直後または内部にCTA |
| スタッフ写真の質がバラバラ | チームとして統一感がない | 同日・同条件で撮影 |
| 顔出しなし理由不明 | 怪しさを感じる | 理由を明記またはイラストで統一 |
