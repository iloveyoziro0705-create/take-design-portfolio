## MAP 03 ｜ 心理トリガー別逆引きマップ

### 無料（ゼロリスク）

> ゼロコストで試せる・受けられると伝える

最強: **CTA-039**（無料相談フル）→ **CTA-006**（無料特典リスト）→ **CTA-011**（LINE無料）

| ID | 使われ方 |
|----|---------|
| CTA-039 | 無料相談タイトル |
| CTA-006 | 無料特典リスト |
| CTA-011 | LINEは無料 |
| CTA-008 | 無料資料請求 |
| CTA-041 | 無料診断 |
| CTA-048 | まず無料で話す |

---

### 緊急性（今すぐやらないと機会を失う）

> 締め切り・期限で「今」行動させる

最強: **CTA-010**（カウントダウン）→ **CTA-040**（初回期限）→ **CTA-033**（期間限定）

| ID | 使われ方 |
|----|---------|
| CTA-010 | カウントダウンタイマー |
| CTA-040 | 初回限定＋期限表示 |
| CTA-033 | 期間限定バナー |
| CTA-007 | 期間内申し込み |
| CTA-050 | 離脱時の最後のオファー |

---

### 希少性（数量・件数が限られている）

> 残り数・定員制で希少感を作る

最強: **CTA-032**（残り枠表示）→ **CTA-033**（期間限定）→ **CTA-007**（初回限定）

| ID | 使われ方 |
|----|---------|
| CTA-032 | 残り○枠表示 |
| CTA-033 | 期間限定バナー |
| CTA-007 | 初回限定（1人1回） |
| CTA-014 | LINE登録特典（先着○名）|

---

### 安心感（リスクがない・失敗しない）

> 不安を解消して決断させる

最強: **CTA-009**（返金保証）→ **CTA-013**（安心材料3点）→ **CTA-039**（勧誘なし等）

| ID | 使われ方 |
|----|---------|
| CTA-009 | 返金保証バッジ |
| CTA-028 | 返金保証シール |
| CTA-013 | 安心材料3点セット |
| CTA-039 | 勧誘なし・秘密厳守 |
| CTA-017 | SSL・プライバシー |
| CTA-048 | まず話を聞くだけ |
| CTA-044 | FAQ疑問解消 |

---

### 権威性（専門家・実績が保証）

> 経歴・資格・受賞で「信頼できる」を証明

最強: **CTA-027**（実績バッジ全部入り）→ **CTA-042**（受賞バッジ）→ **CTA-031**（Google評価）

| ID | 使われ方 |
|----|---------|
| CTA-027 | 資格・受賞バッジ複数 |
| CTA-042 | 受賞・メディア掲載 |
| CTA-031 | Google評価4.5★ |
| CTA-029 | 導入実績○件 |
| CTA-046 | 制作実績50本以上 |

---

### 社会的証明（多くの人が使っている）

> 口コミ・利用者数・企業ロゴで「みんな選んでいる」を示す

最強: **CTA-030**（口コミ直前）→ **CTA-029**（利用者数）→ **CTA-043**（全部入り）

| ID | 使われ方 |
|----|---------|
| CTA-030 | 口コミ引用CTA直前 |
| CTA-029 | 利用者数大数字 |
| CTA-043 | 実績＋口コミ同時 |
| CTA-031 | Google口コミ件数 |

---

### 損失回避（やらないと損をする）

> 「このままでいいですか」「機会を逃す」で行動させる

最強: **CTA-055**（ネガティブ→ポジティブ）→ **CTA-037**（問いかけ）→ **CTA-010**（カウントダウン）

| ID | 使われ方 |
|----|---------|
| CTA-055 | 現状課題提示→解決 |
| CTA-037 | 「悩んでいませんか？」 |
| CTA-050 | 「このまま離脱？特典あります」 |
| CTA-010 | 「期限後は通常価格に戻ります」 |
| CTA-032 | 「あと○席で締め切り」|

---

### 自己投資（未来の自分への価値ある選択）

> 「成長・変化・豊かさ」への投資として提示

最強: **CTA-038**（ビフォーアフター）→ **CTA-054**（成功ストーリー）→ **CTA-047**（ストーリー型）

| ID | 使われ方 |
|----|---------|
| CTA-038 | 「変わった私」の変化訴求 |
| CTA-054 | 成功者の事例 |
| CTA-047 | 「もし〇〇になりたいなら」 |
| CTA-025 | 理想の世界観写真 |

## MAP 09 ｜ スマホ最適化 CTAチェックリスト

### 必須対応（全CTAパターン共通）
- [ ] ボタン高さ: 56px以上（親指タップ）
- [ ] ボタン幅: スマホでは全幅（100%）
- [ ] LINEボタン: `href="https://line.me/..."` タップ動作
- [ ] 電話ボタン: `href="tel:0120-xxx-xxx"` タップで発信
- [ ] テキストサイズ: 最小14px / CTA見出し20〜24px
- [ ] タップ領域: 44×44px以上（iOS Human Interface Guidelines）
- [ ] ボタン間余白: 12〜16px以上（誤タップ防止）

### 固定CTAのスマホ実装
```css
/* スマホ下部固定バー */
.sticky-cta {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  height: 64px;
  background: #fff;
  box-shadow: 0 -2px 8px rgba(0,0,0,0.12);
  display: flex;
  align-items: center;
  padding: 0 16px;
  z-index: 100;
}

/* デスクトップでは非表示（LPによっては常時表示も可）*/
@media (min-width: 768px) {
  .sticky-cta { display: none; }
}
```

### LINEボタン 実装仕様（日本LP標準）
```css
.btn-line {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 10px;
  width: 100%; /* スマホ全幅 */
  max-width: 360px;
  height: 64px;
  background: #06C755;
  color: #fff;
  border-radius: 48px; /* LINE公式に準拠 */
  font-size: 18px;
  font-weight: bold;
  text-decoration: none;
}
```
