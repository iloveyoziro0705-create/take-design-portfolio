## ランク基準

| ランク | スコア範囲 | 定義 |
|--------|-----------|------|
| S+ | 90〜100 | 最高水準。信頼性・CV・感情訴求すべてで傑出 |
| S | 82〜89 | 高水準。ほぼ全シーンで強力な成果 |
| A+ | 77〜81 | 優秀。条件次第でS級に達する |
| A | 72〜76 | 良好。用途が合えば十分な効果 |
| B | 60〜71 | 条件付き。特定業種・用途に限定 |
| C | 〜59 | 補助的使用のみ |

## ⚡ 制作フロー推奨コンビネーション

### CV最大化コンビ（全業種対応）
```
VOICE-028（総合評価バッジ） → VOICE-001（3カード） → VOICE-035（CTA直前大引用） → CTA
```

### 日本LP 美容定番コンビ
```
VOICE-044（評価＋見出し導入） → VOICE-039（B/A＋体験談） → VOICE-016（吹き出し） → CTA
```

```
VOICE-046（ロゴ＋声） → VOICE-013（インタビュー詳細） → VOICE-032（数字実績） → CTA
```

```
VOICE-028（実績評価バッジ） → VOICE-043（動画証言） → VOICE-041（インタビュー交互） → VOICE-035（大引用CTA前） → CTA
```

```
VOICE-019（Google口コミ） → VOICE-011（ベントグリッド） → VOICE-047（CTA統合）
```
