## 推奨コンビネーション

### COMBO-01 ｜ 日本LP王道（美容・サービス業）
```
Hero → Feature → Voice → [CTA-039] → [CTA-034（固定）]
```
CTA-039「無料相談＋特典3点＋LINE」をメインに、CTA-034「スマホ下部固定バー」を常時表示。
ページのどの位置でも離脱させない最強構成。

---

### COMBO-02 ｜ 映像制作（TAKE movie）
```
Hero → Feature（実績・制作フロー）→ Voice（事例口コミ）→ [CTA-046] → [CTA-034（固定）]
```
CTA-046「映像制作特化」でダーク・高品質な仕上げ。固定バーで常時LINE導線を確保。

---

### COMBO-03 ｜ 高単価コンサル（不安解消型）
```
Hero → Feature（強み）→ Voice（実績）→ [CTA-044（FAQ）] → [CTA-048（段階的）]
```
CTA-044「FAQ解消」で最後の疑問を取り除き、CTA-048「まず小さな一歩」で低ハードルCV。

---

### COMBO-04 ｜ SaaS（最小摩擦型）
```
Hero → Feature → Social Proof → [CTA-001] → [CTA-035（ヘッダー固定）]
```
CTA-001のシンプルな1ボタンCTA＋CTA-035のヘッダー固定。余計な情報ゼロで決断を促す。

---

### COMBO-05 ｜ EC・セール（緊急性最大化）
```
Hero（セール告知）→ Feature（商品）→ Voice（レビュー）→ [CTA-010（カウントダウン）] → [CTA-050（離脱防止）]
```
CTA-010でカウントダウン緊急性、CTA-050でエグジットインテントによる離脱防止。

---

### COMBO-06 ｜ 美容LP 初回集客（最速CV型）
```
Hero（初回限定）→ Voice（施術後写真）→ [CTA-040] → [CTA-034（固定）]
```
Featureを省略してシンプルにVoiceのビフォーアフター後、CTA-040「初回限定割引＋LINE」へ。
