## スコア評価軸（各10点 × 10項目 = 100点満点）

1. CV期待値
2. デザイン性
3. 押しやすさ（UX）
4. 安心感
5. 情報整理
6. 視認性
7. スマホ適性
8. 心理設計
9. 再利用性
10. ブランド表現

---

## 心理トリガー分類

| トリガー | 定義 |
|---------|------|
| 希少性 | 数量・件数が限られている |
| 緊急性 | 今すぐやらないと機会を失う |
| 安心感 | リスクがない・失敗しない |
| 権威性 | 専門家・実績が保証している |
| 社会的証明 | 多くの人が使っている |
| 損失回避 | やらないと損をする |
| 限定性 | 特定の条件でのみ得られる |
| 自己投資 | 未来の自分への価値ある選択 |
| 無料 | ゼロリスクで試せる |

### CTA-L-004: フローティング固定型（スクロール追従）

12LP中9LPで画面固定CTAが実装されており、最頻出パターンであることが確認できた。実装は3系統に分かれる。
