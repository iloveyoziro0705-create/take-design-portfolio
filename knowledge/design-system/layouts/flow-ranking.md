## 推奨コンビネーション

### COMBO-01 ｜ 映像制作（TAKE movie 本番LP）
```
Feature（実績・強み）→ [FLOW-039]（制作の流れ）→ Voice（口コミ）→ CTA-046
```
映像制作専用フロー＋安心材料で「頼んでみよう」を自然に引き出す。

---

### COMBO-02 ｜ 美容LP 初回集客
```
Hero（感情型）→ Voice（施術写真B/A）→ [FLOW-034]（施術の流れ）→ [FLOW-042]（安心材料統合）→ CTA-040
```
「施術の流れ」で初来店不安を解消した上でCTAへ。

---

### COMBO-03 ｜ 士業・コンサル（安心型）
```
Feature（強み）→ [FLOW-035]（相談の流れ）→ [FLOW-041]（費用タイミング）→ CTA-048
```
ご相談の流れで「費用はいつ発生するか」まで明示して「まず相談」を促す。

---

### COMBO-04 ｜ SaaS（最小摩擦型）
```
Hero（1ボタン）→ Feature（機能）→ [FLOW-006]（横3ステップ）→ CTA-001
```
横3ステップで「こんなに簡単」を一瞬で伝えて即CV。

---

### COMBO-05 ｜ 採用LP（応募ハードル最小化）
```
Hero（社員写真）→ Feature（職場環境）→ [FLOW-036]（応募の流れ）→ Voice（社員の声）→ CTA-021
```
選考の流れを見せて「応募してみよう」の安心感を作る。

---

### COMBO-06 ｜ 高単価コンサル（段階的説得型）
```
Feature（課題提示）→ [FLOW-050]（段階的Flow・最初の一歩強調）→ [FLOW-043]（Flow＋FAQ）→ CTA-048
```
「まずLINEするだけ」から始まる低ハードルの流れ設計。
